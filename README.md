# AirCasta — AirPlay Mirroring & DropCast для iPhone (Windows & macOS)

**AirCasta** — это нативное десктопное приложение для Windows (10/11) и macOS, превращающее ваш компьютер в полнофункциональный приёмник экрана (**AirPlay Mirroring**) и систему мгновенной передачи файлов (**DropCast**).

### Главное преимущество:
**На iPhone не нужно устанавливать никаких сторонних приложений.**  
Всё работает «из коробки» через встроенные возможности iOS:
* **Повтор экрана (AirPlay):** Пункт управления → «Повтор экрана» → AirCasta (до 4K 60 FPS, Direct3D 11, передача звука).
* **DropCast (Аналог AirDrop):** Наведите камеру iPhone на QR-код на экране ПК → отправляйте фото, видео и файлы без сжатия в Safari на максимальной скорости локальной сети.

## Возможности

1. **AirPlay Screen Mirroring (Экран iPhone на ПК):**
   - Нативное аппаратное декодирование H.264 и H.265 (HEVC).
   - Поддержка разрешений 1080p, 2K, 4K при стабильных 60 кадров/сек.
   - Аппаратный рендеринг через **Direct3D 11 / D3D12** на Windows и **VideoToolbox** на macOS.
   - Полноэкранный режим (`F11` / `Alt+Enter`), сохранение пропорций (книжная/альбомная ориентация).
   - Сверхнизкая задержка (`-vsync no`) и потоковый звук через WASAPI.

2. **DropCast (Двусторонняя передача файлов ПК ⇄ iPhone):**
   - Передача оригиналов фото и 4K видео из медиатеки iOS без сжатия.
   - Передача любых документов, архивов и файлов с iPhone на ПК.
   - Отправка файлов с ПК на iPhone простым Drag & Drop в окно программы.
   - Мгновенная синхронизация буфера обмена (ссылки и текст).
   - Встроенный мастер настройки Брандмауэра Windows в 1 клик.

## 1. Архитектура и техническое исследование AirPlay

### 1.1 Этапы протокола AirPlay Screen Mirroring

| Этап | Протокол / Порты | Назначение |
|---|---|---|
| **Обнаружение** | mDNS / DNS-SD (UDP 5353) | Объявление сервисов `_airplay._tcp.local.` и `_raop._tcp.local.` с параметрами TXT (features `0x5A7FFEE6`, model `AppleTV3,2`, pk, flags). |
| **Установление соединения** | RTSP / HTTP (TCP 7000) | Запросы `GET /info`, обмен характеристиками приемника и клиента. |
| **Согласование ключей (Pair-Verify)** | RTSP POST `/pair-verify` | Обмен эфемерными ключами Curve25519 (X25519) и подписями Ed25519. Вычисление общего секрета `ecdh_secret`. |
| **Инициализация шифрования (FairPlay SAP)** | RTSP POST `/fp-setup` | Двухэтапный рукопожатие FairPlay SAPv2.5 для безопасного обмена сессионным ключом. |
| **Настройка потока (SETUP)** | RTSP `SETUP` | Передача структуры bplist: `streams` с типом `110` (Mirroring) и `streamConnectionID`. Сервер расшифровывает 72-байтный `ekey` алгоритмом FairPlay в 16-байтный AES-ключ. |
| **Приём видеопотока** | TCP (порт 7100) | Поток пакетов с 128-байтным заголовком. Пакеты типа `0x00` расшифровываются AES-128-CTR (`AirPlayStreamKey` + `streamConnectionID`). |
| **Декодирование NAL-юнитов** | H.264 / H.265 (HEVC) | Преобразование AVCC-длин NAL в Annex B (`0x00000001`), добавление SPS/PPS перед ключевыми кадрами IDR, передача в декодер. |
| **Аппаратный рендеринг** | Direct3D 11 / D3D12 / VideoToolbox | Отрисовка кадров с аппаратным ускорением на GPU с сохранением соотношения сторон (вертикальный/горизонтальный режим). |

### 1.2 Анализ существующих открытых проектов

| Проект | Поддержка Mirroring (Видео) | Поддержка Аудио | Лицензия | Статус и совместимость |
|---|---|---|---|---|

## 2. Исследование подключения по USB-кабелю

### Технические аспекты:
Стандартное зеркалирование AirPlay архитектурно разработано Apple как **сетевой протокол уровня L3/L4 (IP)**, использующий мультикаст DNS (mDNS) и RTSP/RTP через TCP/UDP. Обычный USB-кабель сам по себе предоставляет только шину USB (bulk-эндпоинты через драйвер `usbmuxd`), по которой iOS **не ищет** AirPlay-приёмники напрямую.

### Способы реализации USB-подключения:
1. **Режим «Модем по USB» (Personal Hotspot over USB) — РЕКОМЕНДУЕМЫЙ И ПОДДЕРЖИВАЕМЫЙ РЕЖИМ:**
   - При подключении iPhone к компьютеру кабелем Lightning / USB-C и включении режима модема (USB Tethering) в системе создаётся виртуальный сетевой NCM/RNDIS адаптер (*Apple Mobile Device Ethernet*).
   - Между компьютером и iPhone возникает прямое проводное IP-соединение.
   - **AirCasta мгновенно обнаруживается по этому каналу.** Задержка снижается до абсолютного минимума (10–15 мс) без каких-либо радиопомех от перегруженных Wi-Fi сетей.
2. **Протокол QuickTime Screen Capture (CoreMediaIO):**
   - Используется на macOS в QuickTime Player при записи экрана по кабелю. Не является AirPlay, требует закрытых протоколов Apple AVFoundation или реверс-инжиниринговых утилит захвата. На iPhone при этом включается индикатор внешней записи, а не системный AirPlay.

## 3. Безопасность и ограничения DRM

- **FairPlay DRM:** Защищённый видеоконтент (Netflix, Кинопоиск, Apple TV+, Disney+) шифруется коммерческой системой FairPlay DRM с проверкой аппаратных сертификатов HDCP. При попытке зеркалирования такого видео экран приложения остаётся чёрным — это штатное поведение iOS для защиты авторских прав. AirCasta не осуществляет взлом DRM.
- **PIN-код подтверждения:** При включении опции `-pin` в настройках приёмника подключение невозможно без ввода 4-значного кода, который отображается в окне AirCasta.
- **Приватность:** Видеопоток обрабатывается исключительно локально на вашем ПК в оперативной памяти и графическом ускорителе GPU. Никакие данные не передаются во внешние облачные сервисы.

## 4. Установка и запуск

### Системные требования:
- **Windows:** Windows 10 (1809+) или Windows 11 (64-бит).
- **macOS:** macOS 12 Monterey, 13 Ventura, 14 Sonoma, 15 Sequoia (Intel и Apple Silicon M1/M2/M3/M4).
- **iOS:** iPhone или iPad с iOS 9.3 до iOS 18+. Компьютер и iPhone должны быть подключены к одной локальной сети (или по USB-модему).

### Способы запуска на Windows:

#### Вариант 1: Готовая версия (.exe) — Рекомендуется для большинства пользователей
*Не требует установки Python или сторонних библиотек. Всё уже включено в билд.*

1. Скачайте архив **`AirCasta-v1.0-Standalone-Win64.zip`** со страницы **[Releases](https://github.com/Topchikus/AirCasta/releases)**.
2. Распакуйте архив в любую папку.
3. Запустите **`AirCasta.exe`**.

#### Вариант 2: Запуск из исходного кода (Для разработчиков)
1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/Topchikus/AirCasta.git
   cd AirCasta
   ```
2. Запустите:
   ```cmd
   run.bat
   ```
   *(При первом запуске `run.bat` автоматически проверит и установит модули из `requirements.txt`).*

### Сборка нативного бэкенда из исходного кода:

#### Для Windows (через MSYS2 UCRT64):
```cmd
scripts\build_backend_windows.bat
```
Скрипт автоматически проверит MSYS2, установит зависимости (gcc, cmake, ninja, gstreamer, libplist, openssl), скомпилирует `uxplay.exe` с внутренним mDNS и поместит готовый файл в `bin/`.

#### Для macOS (через Homebrew):
```bash
chmod +x scripts/build_backend_macos.sh
./scripts/build_backend_macos.sh
python3 main.py
```

## 5. Графический интерфейс AirCasta

- **Главный переключатель:** Включение/выключение обнаружения AirPlay в один клик.
- **Имя приёмника:** Изменение имени компьютера, отображаемого на экране iPhone.
- **Интерактивная плашка PIN:** Мгновенный показ 4-значного кода авторизации при запросе с телефона.
- **Панель телеметрии:** Мониторинг в реальном времени:
  - Модель подключенного устройства (например, *iPhone 15 Pro*) и его IP-адрес.
  - Текущая частота кадров (FPS: до 60 кадров/сек).
  - Расчётная задержка (Latency: в миллисекундах).
  - Разрешение и ориентация (альбомная / книжная с динамической автоподстройкой).
- **Управление звуком:** Регулятор громкости и кнопка мгновенного отключения звука (Mute).
- **Полноэкранный режим:** Кнопка «Полный экран» или горячая клавиша `Alt + Enter` (`F11`).
- **Сетевая диагностика:** Инструмент проверки сетевого профиля Windows (Private/Public), открытости портов 7000/TCP и 5353/UDP, статуса изоляции Wi-Fi (AP Isolation) и автоматическая генерация правила для Брандмауэра Windows.

## 6. Устранение неполадок (Troubleshooting)

1. **iPhone не видит ПК в списке «Повтор экрана»:**
   - Нажмите в AirCasta кнопку **«🩺 Сеть и Брандмауэр»** для запуска автодиагностики.
   - Убедитесь, что сетевой профиль Windows переключен в режим **«Частная сеть»** (Private).
   - Добавьте правило брандмауэра в PowerShell (от имени Администратора):
     ```powershell
     New-NetFirewallRule -DisplayName "AirCasta AirPlay Receiver" -Direction Inbound -Program "C:\путь\к\AirCasta\bin\uxplay.exe" -Action Allow -Profile Any -Protocol Any
     ```
   - Проверьте настройки роутера: функция **«AP Isolation»** (или «Изоляция клиентов») должна быть **выключена**.
2. **Задержка или рывки:**
   - В настройках AirCasta включите опцию **«Режим минимальной задержки (-vsync no)»**.
   - Переключитесь на диапазон Wi-Fi 5 ГГц вместо 2.4 ГГц или воспользуйтесь режимом USB-модема.
